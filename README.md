# 旅行记账台

> 多币种 · AA 分账 · 离线可用的旅行记账 PWA。纯前端单文件，无后端、无账号、数据完全本地。

装到手机桌面就是一个全屏独立 App，断网也能照常记账。

---

## ✨ 功能特性

### 💰 记账
- **多行程管理**：每趟旅行独立记账，可新建 / 切换 / 重命名，编辑名称、起止日期和预算
- **多币种**：自定义币种与汇率，自动换算到基准币；金额内部用整数「分」存储，避免浮点误差累积
- **分类记账**：内置常用分类（交通 / 餐饮 / 住宿 等）与图标，区分收入与支出
- **快速日期**：一键选择今天 / 昨天，记账更顺手

### 👥 AA 分账
- **成员管理**：添加同行成员，每笔消费可选「谁付的钱」与「AA 给哪几位」
- **智能结算**：一趟旅行结束，自动算清谁该转给谁多少；用贪心算法把还款笔数压到最少
- 支持**标记已还**、**一键复制**结算结果

### 📊 统计与报表
- **预算进度环**：实时显示花费占预算的比例，超支自动变红预警
- **分类饼图 / 趋势图**：钱花在哪、按天的走势一目了然
- **报表**：一键生成文字报表，可复制或打印

### 🗂️ 其他
- **待办清单**：行程待办事项，可勾选完成、删除
- **深色模式**：手动切换 / 跟随系统，刷新无闪烁（FOUC 已处理）
- **导出 / 导入备份**：换设备或换网址前先备份，避免数据丢失

## 📱 在线体验 / 安装

部署到 GitHub Pages 后，在手机浏览器打开：

```
https://<你的用户名>.github.io/<仓库名>/
```

- **安卓**：用 Chrome 打开 → 右上角 ⋮ → *添加至主屏幕* / *安装应用*
- **iOS**：用 Safari 打开 → 分享 → *添加到主屏幕*
- **桌面**：Chrome / Edge 地址栏右侧的安装图标

> ⚠️ 必须通过 `https` 网址访问才能安装和离线使用；本地 `file://` 双击打开只有网页功能，无法装成 App。

## 💻 本地运行

零依赖，无需安装任何东西。但 PWA（安装、离线）必须走 `http(s)`，所以推荐起个本地服务：

```bash
# 方式 1：Python（自带）
python -m http.server 8080

# 方式 2：Node
npx serve
```

然后浏览器访问 `http://localhost:8080/`。

只想快速看一眼？也可以直接双击 `index.html` 用浏览器打开，但离线缓存和安装功能不会生效。

## 🚀 部署到 GitHub Pages

1. 新建一个 **Public** 仓库，把这 4 个文件上传到仓库**根目录**：
   ```
   index.html   manifest.webmanifest   sw.js   icon.svg
   ```
   > 主文件**必须叫 `index.html`**（仓库根目录的默认页），否则根链接会报 404。
2. 进仓库 **Settings → Pages**：
   - *Build and deployment → Source*：`Deploy from a branch`
   - *Branch*：`main` / `(root)` → **Save**
3. 等约 1 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

更新代码后重新上传或 `git push`，Pages 会在几十秒内自动更新。

## 🔒 数据与隐私

- **100% 本地存储**：所有数据保存在浏览器 `localStorage`，没有服务器、没有账号、不会上传任何信息到任何地方。
- **数据按网址隔离**：`https://...github.io/xxx/` 和 `file://` 本地打开的数据**互不相通**。更换访问网址前，务必先在「更多 → 导出备份」。
- localStorage 键名前缀 `wb_travel_*`（records / todos / budget / trips 备份 / current 等）。

## 📝 说明

- 金额内部以「分」为单位做整数运算，多币种换算的舍入误差已尽量压缩；反复切换基准币时仍可能出现极小误差，属正常现象。
- 首次打开会注册 Service Worker，**第二次起**离线可用。更新后若手机仍显示旧版：在 Chrome 里长按刷新 → *清空缓存并硬性重新加载*。
